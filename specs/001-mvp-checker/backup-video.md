# T019: запасне відео демо

17.11.2026 записано **60-секундне відео справжнього локального Streamlit**
зі синтетичним документом T018. Це екранний запис виконання, а не намальована
анімація чи підставлені звіти. Публічний хмарний сценарій цим не перевірено.

Відео в поточному workspace:
`tmp/t019/recorded/Оформлено_демо_60с.mp4` — 891 729 байтів,
1440 × 900, H.264, 2 кадри/с, 60,000 с. Воно без озвучення, з вбудованою
українською доріжкою субтитрів (`mov_text`, `ukr`, увімкнена типово).
Окремий файл — `demo.uk.srt` у тій самій теці. Для показу без мережі
збережіть MP4 на пристрої заздалегідь; репліки є в [сценарії T018](demo-script.md).
Не заявлено перевірки на конкретному пристрої захисту або відеопрогравачі.

Усі дії вмістилися в запис. Переглянуто вихідний кадр R03, пізній кадр R08

кнопка завантаження й ручний статус видимі. Повне декодування MP4 через

підтвердила R08 як єдину помилку, 7 ручних пунктів, незмінність тексту,
всіх ZIP-частин поза основним документом і SHA-256 оригіналу.

Докази поза Git: `recording-evidence.json`, `ffprobe.json`, `encoded-44s.png`,

## Відтворення запису

Потрібні Node 22+, локальні Chromium і FFmpeg, установлене Python-середовище.
У першому терміналі запустіть наявний застосунок на loopback:

```bash
uv run --no-sync streamlit run app/streamlit_app.py --server.address 127.0.0.1 --server.port 8502
```

У другому терміналі, з кореня репозиторію:

```bash
uv run --no-sync python scripts/make_demo.py tmp/new-pitch-input
node scripts/record_demo.mjs tmp/new-pitch-input/Демо_10_помилок.docx tmp/new-pitch-recording
```

Вибирайте нові теки: скрипти не замінюють наявні артефакти. Скрипт запису
працює лише з локальним сервером `127.0.0.1:8502`; він справді вибирає файл,
перевіряє, відкриває звіт копії та натискає завантаження. Власний профіль
Chromium видаляється, процес закривається; жодних студентських робіт,
публікації, облікових записів чи повідомлень третім особам немає.
Після запису зупиніть запущений локальний Streamlit.

`node --check scripts/record_demo.mjs`, перевірка пробілів і заборона документів
у Git пройшли. Python-код у T019 не змінювався: останні повні перевірки T018
дали 872 пройдені тести; повторний запуск цієї незміненої вибірки не заявлено.
Окреме рев'ю вказало на потребу перевірки пізніх дій і справжньої копії;
ці перевірки виконано, а скрипт додатково відхиляє запізнілі дії.
Перший запуск у sandbox не зміг запустити Chromium, його FAIL збережено
в `tmp/t019/recording-evidence.json`; успішний запис зроблено окремо
з дозволеним host-доступом. Це окремі результати.
