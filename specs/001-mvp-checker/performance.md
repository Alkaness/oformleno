## Відтворення

Потрібні встановлені LibreOffice і `pdfinfo`, крім Python-середовища проєкту.
З кореня checkout, у нову тимчасову теку:

```bash
uv run --no-sync python scripts/benchmark_check.py
```

Або в явно задану нову теку:

```bash
uv run --no-sync python scripts/benchmark_check.py tmp/new-benchmark
```

Скрипт відмовляється замінювати наявні артефакти. Попередній запуск у
`tmp/t020/` підтвердив 30 сторінок, але зупинився через помилкове очікування
лише 7 ручних висновків замість 13; він не має фінального результату.
Виправлено саме очікування, не документ чи правила. Повторний окремий
запуск `verified/` завершився успішно. Наданий user замір 0,83 с на
100 сторінках зберігається як повідомлення user, а не наша перевірка T020.

Незалежне рев'ю скрипта й JSON не має відкритих зауважень. Повні локальні
перевірки після додавання інструментів: Ruff, форматування 87 файлів,
**872 pytest-тести пройшли**. Після уточнення одного assert повторно
перевірено Ruff/форматування зміненого скрипта; поведінка продукту не змінена.
Перевірки Git-документів і пробілів пройшли. Нового GitHub CI не було.
